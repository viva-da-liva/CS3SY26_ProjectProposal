### Project Description:
Music shops are one of the less talked about types of shops in the world, giving aspiring music shop owners not a large foundation to work with. Our project is a music shop simulator that aims to serve as a baseline or model for aspiring music shop owners, letting them learn and experiment with values to get the best sales. Our project will have a Shop class with a location, staff, stock, balance, credits, and arrays of orders and promos. It can buy instruments and manage staff. There will also be an Instrument class with subclasses depending on their colloquial category and features. All instruments can play a sound. There will also be a Customer class which does the actual purchasing and selling of instruments. There will be a Worker class with different subclasses depending on what division they’re in, and they can perform the work they’re supposed to do, as well as get a raise, attendance, and salary. Finally, is an Order class which takes a Customer and Instrument class. This will have specific types of orders/interactions between the shop and the customer. Each subclass has unique qualities and methods that set it apart from each other.
